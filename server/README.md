## Server
  - gRPC services to handle all clients events in the game. (entities lifecycle, players movements...)
  - The world engine which handle the entities behaviours, spawn ...

## Integration tests

gRPC integration tests validate the server through its public gRPC API using the generated client and a real database.

- Located in [tests](./tests/) folder.
- It uses the gRPC client code, generated by the [common](../common/) library to test the gRPC API services.

#### How to run

```bash
# Start the game server and the database
docker compose up

# Populate the database with test data
./server/tests/seed.sh

# Run the server integration tests
cargo test -p server

# Stop the server and database, and remove the database volume, deleting all test data.
docker compose down -v
```
